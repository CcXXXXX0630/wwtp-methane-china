## 3. Redistributed third-party data

### 3a. `data/中国污水处理厂数据集.xlsx` — CC BY 4.0

Derived from:

> Zhou, S., Gong, H., Chen, X., Wang, X., Wang, H., Zhang, Y., Zhu, D.,
> Cao, X., Li, S., Dai, X. (2024). A Dataset of Distribution and
> Characterization of Underground Wastewater Treatment Plants in China.
> figshare. https://doi.org/10.6084/m9.figshare.26085265
>
> Data Descriptor: *Scientific Data* **11**, 941.
> https://doi.org/10.1038/s41597-024-03815-x

Original licence: CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/), which permits redistribution
and adaptation with attribution.

**Changes made to the original.** The 14 column headers were translated from
English to Chinese. No values were altered, and no rows were added or removed.
The mapping is:

| Original header | Header in this file |
|---|---|
| Type_WWTP | 类型_污水处理厂 |
| Name_WWTP | 名称_污水处理厂 |
| Local_province | 省份 |
| Local_city | 城市 |
| Local_lon | 经度 |
| Local_lat | 维度 |
| Scale_WWTP | 规模_污水处理厂(104m3/d) |
| Process_category | 工艺类别 |
| Process_sub-category | 工艺类别具体 |
| Discharge_standard_WWTP | 污水处理排放标准 |
| Sample_COD | 污水中化学需氧量的年平均浓度(mg/L) |
| Sample_NH3-N | 污水中氨氮(NH3-N)的(mg/L) |
| Construction_Year | 建设年份 |
| Source | 来源 |

Only the `A-WWTP` sheet (above-ground plants) is used by this analysis.

Note that the *Data Descriptor article* carries a more restrictive licence
(CC BY-NC-ND 4.0) than the *dataset* it describes. The CC BY 4.0 terms above
apply to the figshare deposit, which is what is redistributed here.

### 3b. `data/sun_S2_capacity.csv`, `data/sun_S3_periods.csv` — CC BY-NC 4.0

Transcribed from Tables S2 and S3 of the Supplementary Materials of:

> Sun, C., Liu, Y., Ciais, P., Broquet, G., Zheng, B., Wang, H., Chen, H.
> (2026). Measurement-based assessment reveals key drivers and mitigation
> potential of methane emissions from China's wastewater treatment.
> *Science Advances* **12** (15), eaec0536.
> https://doi.org/10.1126/sciadv.aec0536

Original licence: CC BY-NC 4.0
(https://creativecommons.org/licenses/by-nc/4.0/), which permits
redistribution and adaptation **for non-commercial purposes only**, with
attribution.

**Changes made to the original.** Numerical values were transcribed into CSV
form without alteration. `sun_S2_capacity.csv` contains plant identifier,
design capacity and process type; `sun_S3_periods.csv` contains plant
identifier and measured emission rate per observational period.

## Implication for the record as a whole

Because files under 3b carry a NonCommercial condition, **the deposit as a
whole may not be used for commercial purposes**. A repository record
containing these files should be registered under CC BY-NC 4.0.

If a fully permissive (CC BY 4.0) record is preferred, delete the two files
listed under 3b before depositing. `run_all.py` detects their absence, skips
the validation section, and prints instructions for obtaining them from the
publisher; every other result still reproduces.
